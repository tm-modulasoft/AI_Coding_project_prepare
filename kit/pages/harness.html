Prepare the harness

Put the agent runtime in place before writing project conventions. The agent writes the files and restores skills. You install missing Cursor marketplace plugins once (/add-plugin — there is no CLI).

First time on a host? Open this kit on GitHub, paste the README prompt into an agent on the local project. The agent fetches kit/ and restores skills from GitHub.

What this step writes

File Role
.cursor/settings.json IDE client defaults. Enables the default plugin set after you install them.
.cursor/cli.json CLI client project layer (permissions only). Global CLI prefs stay in your user cli-config.json.
skills-lock.json Copied from kit harness-defaults/skills-lock.json if the host has none. Commit this file.
AI_CODING_README.md Human cheat sheet copied from kit harness-defaults/AI_CODING_README.md. Workflow, skill cmds, plugins. Not a second AGENTS.md.

Skills install (agent runs this)

The lockfile harness-defaults/skills-lock.json lists GitHub skill sources. After it is copied to the host git root, the agent must restore them (network). You should not clone skill repos yourself. Fallback if the agent failed:

Host git root

npx skills experimental_install --yes

Installs land in .agents/skills/ (gitignored). The lockfile stays tracked. Other clients (Cursor CLI, Claude Code, Codex, …) can use the same canonical folder.

Plugins (you, only if missing)

Writing settings.json does not download marketplace plugins, and there is no shell command that does. If the agent says a plugin is not already on this machine, paste that line in Cursor chat on the host:

Cursor chat

/add-plugin cursor-team-kit
/add-plugin context7-plugin
/add-plugin sonatype-cursor-plugin
/add-plugin modern-web-guidance

Then reload the window. Context7 and Sonatype need a key in Customize ("key": true in settings). Never commit the key. Skip any plugin the agent reports as already installed.

Default plugin block the agent merges into .cursor/settings.json: 

{
  "plugins": {
    "cursor-team-kit": { "enabled": true },
    "context7-plugin": { "enabled": true, "key": true },
    "sonatype-cursor-plugin": { "enabled": true, "key": true },
    "modern-web-guidance": { "enabled": true }
  }
}

Native rules (always-on)

Cursor loads .cursor/rules/*.mdc with alwaysApply: true on every chat — project-level pre-prompt. The kit copies harness-defaults/ai-coding-native-rules.md into ai-coding-native-rules.mdc. Optional: paste the same body into Customize → Rules → User Rules if you want it on every repo on this machine.

If a tool cannot load that rule file, step 2 still writes a short Tools stanza in AGENTS.md: Context7 MCP for library docs (not client search), Sonatype for versions and security, gh for GitHub.

IDE and CLI defaults

  • IDE: project .cursor/settings.json (plugins above).
  • CLI: project .cursor/cli.json — permissions only. Do not overwrite global ~/.cursor/cli-config.json unless you asked.
