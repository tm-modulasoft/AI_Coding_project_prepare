Prepare the harness

Put the agent runtime in place before writing project conventions. This step enables default plugins, restores skills from a lockfile, ignores the local skills install folder, and injects house rules at Cursor’s always-on (pre-prompt) layer.

What this step writes

File Role
.cursor/settings.json IDE client defaults. Enables the default plugin set after you install them.
.cursor/cli.json CLI client project layer (permissions only). Global CLI prefs stay in your user cli-config.json.
skills-lock.json Copied from kit one_offs/skills-lock.json if the host has none. Commit this file.
.gitignore Ignores .agents/skills/ so restored installs stay off git.
.cursor/rules/native-rules.mdc Always-on native rule. Body from kit one_offs/native-rules.md.

First install: plugins

Writing settings.json does not download marketplace plugins. In Cursor chat on the host project, run each of these once:

Cursor chat

/add-plugin cursor-team-kit
/add-plugin context7-plugin
/add-plugin sonatype-cursor-plugin
/add-plugin modern-web-guidance

Then reload the window. Context7 and Sonatype need a key in Customize ("key": true in settings). Never commit the key.

Default plugin block the agent merges into .cursor/settings.json:

{
  "plugins": {
    "cursor-team-kit": { "enabled": true },
    "context7-plugin": { "enabled": true, "key": true },
    "sonatype-cursor-plugin": { "enabled": true, "key": true },
    "modern-web-guidance": { "enabled": true }
  }
}

First install: skills

After skills-lock.json is at the host git root, restore the default general + agentic-coding skills:

Host git root

npx skills experimental_install

Installs land in .agents/skills/ (gitignored). The lockfile stays tracked. Other clients (Cursor CLI, Claude Code, Codex, …) can use the same canonical folder.

Native rules (always-on)

Cursor loads .cursor/rules/*.mdc with alwaysApply: true on every chat — project-level pre-prompt. The kit copies one_offs/native-rules.md into native-rules.mdc. Optional: paste the same body into Customize → Rules → User Rules if you want it on every repo on this machine.

If a tool cannot load that rule file, step 2 still writes a short Tools stanza in AGENTS.md: Context7 MCP for library docs (not client search), Sonatype for versions and security, gh for GitHub.

IDE and CLI defaults

  • IDE: project .cursor/settings.json (plugins above).
  • CLI: project .cursor/cli.json — permissions only. Do not overwrite global ~/.cursor/cli-config.json unless you asked.
